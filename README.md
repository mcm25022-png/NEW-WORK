# SRIKANTH - Educational Pages Project

This repository contains educational pages about the 2024 biographical drama film **Srikanth**.

## Project Overview

**Film:** Srikanth (2024)
**Director:** Tushar Hiranandani
**Lead Actor:** Rajkummar Rao
**Subject:** Based on the real-life story of Srikanth Bolla, a visually impaired entrepreneur

## Contents

This project includes 5 comprehensive pages:

1. **Introduction** - Overview of the film and its significance
2. **Film Story Plot** - Detailed narrative of Srikanth's journey
3. **Characterization** - Analysis of main and supporting characters
4. **Mise-en-Scène** - Film aesthetics and technical aspects
5. **Importance for Indian Audiences** - Social impact and relevance

Each page includes space for up to 2 images to enhance the educational content.

## Files

- `srikanth-pages.md` - Complete content with image placement guides
- `image-sources.md` - Recommended sources for obtaining images

## Purpose

This material is designed as student-friendly educational content about the film, suitable for classroom discussion, film analysis, or personal learning.
