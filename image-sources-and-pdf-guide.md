## Steps to Create PDF with Images

### METHOD 1: Google Docs (Recommended - Easy & Free)

1. **Copy Content:**
   - Go to https://docs.google.com/document/create
   - Copy all content from `srikanth-pages.md`
   - Paste into Google Docs

2. **Add Images:**
   - Click "Insert" → "Image"
   - Choose "Search the web" or "Upload from computer"
   - Search for each image by title (e.g., "Srikanth 2024 poster")
   - Insert at designated locations
   - Resize to fit page layout (recommended: 4-5 inches wide)

3. **Format:**
   - Add page breaks before each new section
   - Adjust spacing and alignment
   - Add title page if desired

4. **Download as PDF:**
   - Click "File" → "Download" → "PDF Document"
   - Save to your computer

### METHOD 2: Microsoft Word

1. **Create Document:**
   - Open Microsoft Word
   - Copy content from `srikanth-pages.md`
   - Paste into Word document

2. **Insert Images:**
   - Click "Insert" → "Pictures"
   - Choose online or local images
   - Place at image placeholder locations
   - Resize and format

3. **Add Page Breaks:**
   - Position cursor before each section heading
   - Press Ctrl+Enter (Windows) or Cmd+Enter (Mac)

4. **Export to PDF:**
   - Click "File" → "Export as PDF"
   - Choose location and filename
   - Click "Export"

### METHOD 3: Canva (Designed - Professional Look)

1. **Create Presentation:**
   - Go to https://www.canva.com/
   - Sign up (free account available)
   - Click "Create a design" → "Document"

2. **Create Slides:**
   - One slide per page section
   - Add heading
   - Add descriptive text
   - Add images

3. **Add Images:**
   - Click "Elements" or "Uploads"
   - Search for Srikanth movie images
   - Insert and arrange on slide

4. **Download:**
   - Click "Download" → "PDF"
   - Adjust quality settings
   - Download to computer

### METHOD 4: LibreOffice (Free Alternative)

1. **Create Document:**
   - Download LibreOffice from https://www.libreoffice.org/
   - Open Writer
   - Paste content

2. **Insert Images:**
   - Click "Insert" → "Image"
   - Browse and select images
   - Resize as needed

3. **Export to PDF:**
   - Click "File" → "Export as PDF"
   - Configure settings
   - Save
